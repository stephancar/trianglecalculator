# Triangle Calculator

Right-triangle calculator: enter the two legs, get the hypotenuse, angles, area and perimeter. Handy for roofs, ramps, stairs and shelf braces.

**▶ Use it: https://www.steefware.com/trianglecalculator/**

Read how it works: [The right triangle: hypotenuse, angles and area explained](https://www.steefware.com/blog/triangle-calculator.html)

## About

- Single self-contained `index.html` — vanilla JS, no build step, no dependencies to install
- No cookies, no ads, no accounts, no tracking; everything runs locally in your browser
- Part of [steefware.com](https://www.steefware.com/), a collection of simple free web tools

## Local development

Open `index.html` in a browser, or serve the folder:

```bash
python -m http.server
```
